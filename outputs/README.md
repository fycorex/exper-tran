# Committed experiment results

This directory contains the small, structured outputs requested for archival
and review across the repository's historical experiment runs. Committed files
include CSV summaries, JSON/JSONL diagnostics and manifests, test reports, tap
records, and audit artifacts.

Large or reproducible runtime artifacts remain excluded: adversarial and
canonical PNGs, model-representation caches, service logs, and model weights.
Those files are not required to inspect the reported metrics and would make the
Git history unnecessarily large.
